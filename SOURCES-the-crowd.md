# The Crowd: A Study of the Popular Mind — publication and source record

- **Original:** Gustave Le Bon, *Psychologie des foules* (1895), French; public domain in the United States.
- **English:** *The Crowd: A Study of the Popular Mind*, public-domain English text, Project Gutenberg eBook #445, https://www.gutenberg.org/ebooks/445. Locally hosted file: `public/books/the-crowd-gustave-le-bon-english.txt` (332,453 characters after removal of unrelated Gutenberg export preamble and trailing footer).
- **French:** *Psychologie des foules*, complete original French text, Project Gutenberg eBook #24007, https://www.gutenberg.org/ebooks/24007. Locally hosted HTML text file: `public/books/psychologie-des-foules-gustave-le-bon-original-francais.html`. The source keeps the publisher's front matter and book ending; Gutenberg distribution/license boilerplate was omitted.
- **English reader:** `the-crowd.html` uses the Ophelia browser/device English narrator, page controls, voice, speed, text size, evening mode, bookmarks and saved progress.
- **Original French reader:** `psychologie-des-foules-original-francais.html` is read-only, locally hosted, without a narration button; includes pagination, text-size adjustment and saved position.
- **Cross-links:** Original-language link directly beneath the English heading and return link on the French edition. Both render from local repository assets; neither requires visiting Project Gutenberg to read.
- **Artwork:** `public/art/the-crowd-cover.svg` is newly authored Ophelia typographic artwork in a period-inspired style, NOT an authentic historical binding.
- **Catalog:** Main bookshelf card added to `index.html`; genre `Psychology & Philosophy` added to `catalog.html`.
- **Editorial context:** Important historical work, but Le Bon's generalizations about groups and populations should not be mistaken for contemporary established psychological evidence.
