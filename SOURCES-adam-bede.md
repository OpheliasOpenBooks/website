# Adam Bede — public-domain source and reader

- Author: George Eliot (Mary Ann Evans), 1859. Original English-language novel.
- Text rights: The original text is public domain in the United States; verified against Project Gutenberg eBook 507: https://www.gutenberg.org/ebooks/507.
- Scope: six books, 55 chapters and epilogue. Reader code checks that chapters I–LV occur sequentially and the epilogue is present, and rejects truncated source files.
- Text source: public-domain Gutenberg transcription mirrored as https://raw.githubusercontent.com/GITenberg/Adam-Bede_507/master/507-0.txt. Unlike some other volumes, the source text currently loads directly from the public mirror rather than being duplicated into this repository; this should be converted to a locally hosted verified text edition when practical.
- Cover: https://raw.githubusercontent.com/GITenberg/Adam-Bede_507/master/cover.png, a GITenberg cover graphic. Do not claim it is a historical first-edition illustration without separate evidence.
- Reader: `adam-bede.html`. Uses `public/js/ophelia-narration.js`, browser speech synthesis, voice/rate controls, auto-turn, saved page, and bookmarks. **No prerecorded third-party audio** is used.
- Catalog: `index.html` bookshelf entry, discovered automatically by `catalog.html`; category Literary Fiction.
- Verification: JavaScript syntax passes compilation checks. Live browser rendering, successful remote text load, and actual audio playback have not been tested in this session.
